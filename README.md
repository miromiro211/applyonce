# ApplyOnce

프로필을 한 번 저장해두면, 어떤 공고와 지원서 양식을 만나도 AI가 자동으로 초안을 채워주는 서비스입니다.

이 레포는 두 부분으로 구성됩니다.

```
applyonce/
├── web/         # 웹 앱 - 프로필 저장, 문서 업로드, AI 자동 작성, 원본 PDF 오버레이
└── extension/   # 크롬 확장 프로그램 - 구글폼 자동 채움
```

## 구성

| 폴더 | 설명 | 실행 방법 |
|---|---|---|
| [`web/`](./web) | Node.js + Upstage Studio 에이전트 기반 웹 앱 | [`web/README.md`](./web/README.md) 참고 |
| [`extension/`](./extension) | 구글폼 자동 채움 크롬 확장 프로그램 | [`extension/README.md`](./extension/README.md) 참고 |

## 빠른 시작

1. **웹 앱 먼저 실행** (`web/` 폴더 안내 따라 `.env` 설정 후 `npm install && npm start`)
2. 브라우저에서 `localhost:3000` 접속해 프로필 저장, 공고문/지원서 양식으로 자동 초안 생성 테스트
3. **확장 프로그램 설치** (`chrome://extensions` → 개발자 모드 → `extension/` 폴더 로드)
4. 구글폼 페이지에서 확장 프로그램으로 자동 채우기 테스트

## 아키텍처 요약

```
[웹] 프로필 저장 ──────────────┐
                              ├──> 서버(profile-store.json)
[웹] 공고문 + 지원서 양식 업로드 ─┤        │
                              │        │  (확장 프로그램이 이 API로 프로필 동기화)
                              ▼        ▼
                    Upstage Studio 에이전트 (Parse → Extract → Instruct)
                              │
                              ▼
                    필드별 자동 작성 결과 (profile / ai_generated / manual_required)
                              │
              ┌───────────────┴───────────────┐
              ▼                               ▼
     웹 미리보기 (편집 가능)          원본 PDF에 그대로 오버레이
                                    (pdfplumber 구조 분석 + 나눔고딕 임베드)

[확장 프로그램] 구글폼 페이지에서
   1) 프로필 값으로 즉시 채움 (규칙 기반)
   2) 남은 서술형은 Upstage Solar Chat API로 생성 (AI 기반)
```

## 검증된 케이스

- 표 형태 지원서 양식
- "라벨: ___" 자유 양식
- 표 + 자유 양식 혼합 문서
- 서로 다른 도메인의 공고 3종 (IT 인턴 / 마케팅 / UX 디자인)

## 알려진 한계 (향후 확장 예정)

- 스캔본(텍스트 레이어 없는 PDF)은 미지원 — OCR 단계 추가 필요
- 지원서 내 체크박스 표기(☐/☑), 병합 셀 표는 미지원
- 구글폼 확장 프로그램은 드롭다운 미지원, 라디오/체크박스는 규칙 기반 매칭만 지원
- 네이버폼 등 타 플랫폼 어댑터는 아직 없음 (구조는 확장 가능하게 설계)
